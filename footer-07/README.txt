EVODEK Footer 07

定位：浅色中文社群导航型 Footer。

设计特点：
- 桌面端最大内容宽度为1200px
- 左侧为品牌文字、中文简介、4个中性频道符号和二维码区域
- 右侧为产品相关、服务支持、关于我们3组导航
- 桌面端3组导航全部展开
- 平板端保持左右布局并压缩列宽和间距
- 手机端3组导航默认收起，同一时间只展开1组
- 桌面端和移动端共用一套HTML内容
- 使用真实button、ARIA属性和inert管理折叠状态及焦点
- CSS Grid 0fr/1fr实现平滑展开动画
- JavaScript失效时仍然显示全部导航

资源说明：
- foot-logo.svg为优化后的响应式矢量Logo，使用viewBox和currentColor
- Logo已移除固定宽高、冗余mask和展开描边路径
- qr-placeholder.svg是不包含有效内容的二维码占位图
- 正式上线前必须替换为真实、可验证的二维码
- beianico.png用于公安备案信息旁的图标
- ICP和公安备案号码均保留“请替换”提示，不包含其他网站的信息
- 4个频道图标均为中性几何SVG，不对应任何第三方平台

正式接入前：
1. 替换Logo文字、品牌简介和页面链接。
2. 替换频道链接和频道名称。
3. 用真实二维码替换qr-placeholder.svg。
4. 填写网站真实的ICP和公安备案信息。
5. 核对版权主体和年份。
6. 删除index.html中的.demo-space演示区域。
