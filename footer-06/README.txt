EVODEK Footer 06

定位：深色圆角卡片式企业信息 Footer。

设计特点：
- 桌面端：品牌介绍、快捷链接、联系方式、扩展入口四列布局
- 平板端：四个信息区转换为两列布局
- 手机端：品牌信息保持可见，三个信息组默认收起
- 手机端同一时间只展开一个信息组
- 桌面端和移动端共用一套HTML内容
- 使用真实button、ARIA属性和inert管理折叠状态与焦点
- CSS Grid 0fr/1fr实现平滑展开动画
- JavaScript失效时仍显示全部内容
- 底部版权、支付方式和法律链接响应式排列

中性图标策略：
- 不使用参考图中的第三方平台名称或Logo
- 不使用第三方社交平台品牌图标
- 不使用第三方支付品牌Logo
- 所有平台、社交和支付图标均为项目内原创的基础几何SVG
- Product Hub、Project Studio、Design Desk等名称只用于结构演示
- Wallet、Card、Secure、Transfer只表示通用支付类别

正式接入前：
1. 替换示例邮箱、工作时间和联系方式。
2. 替换所有页面链接和通道链接。
3. 只保留网站实际支持的支付类型。
4. 核对版权主体、年份和法律页面地址。
5. 删除index.html中的.demo-space演示区域。
