EVODEK Footer 04

定位：MEGA 式统一响应式企业导航 Footer。

特点：
- 一套 HTML 同时服务桌面端和移动端，不复制菜单数据
- 桌面端使用 12 列外层网格：品牌区 4 列、导航区 8 列
- 导航区使用 4 列分组布局
- 移动端导航在上、品牌信息在下
- 移动端菜单默认收起，同一时间仅展开一组
- 使用 button、aria-expanded、aria-controls 和 hidden 提升可访问性
- JavaScript 失效时仍显示完整菜单
- 复用 EVODEK Logo、社交媒体 SVG 和认证图片
- 原生 HTML / CSS / JavaScript，无第三方依赖

正式接入前：
1. 替换示例页面链接和社交媒体 URL。
2. 根据网站实际信息调整栏目名称和链接。
3. 删除 index.html 中仅用于预览的 .demo-space。
4. WordPress 项目建议从菜单或配置数据生成导航组，继续保持单一数据源。
